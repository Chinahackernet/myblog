# 课程覆盖矩阵

## 已覆盖

- KVM/QEMU/libvirt、虚拟机生命周期、磁盘映像
- Docker/OCI、镜像、网络、卷、Dockerfile、Registry、资源与安全
- LVS、Nginx、HAProxy、Varnish、Keepalived
- Tomcat、MySQL/MariaDB、复制/备份、权限、Redis
- Zabbix、ELK、Jenkins/GitLab、ZooKeeper
- Kubernetes 架构、工作负载、Service、存储、安全、网络、调度、Helm、生产治理

## 仍需深入的生产专题

以下内容属于课程表中的高级实验，不能用一页概述替代完整实验：

1. KVM bridge、cloud-init、NUMA/hugepages、在线迁移、快照链与灾备。
2. Docker Compose、镜像签名/扫描、Compose 发布、卷备份和 rootless 模式。
3. LVS NAT/DR/TUN 多节点演练、连接追踪和调度器高可用。
4. Nginx PHP-FPM、缓存、限流、WebSocket、TLS 续期和配置灰度。
5. HAProxy 动静分离、四/七层混合、TLS、连接排空和统计接口安全。
6. Keepalived 脑裂防护、通知脚本、优先级和故障演练。
7. Tomcat JDK/线程池/JVM、会话复制、Memcached 和滚动发布。
8. MySQL 索引与执行计划、慢查询、半同步、MHA/Galera、时间点恢复。
9. Redis Sentinel/Cluster、槽位迁移、内存淘汰、ACL 和灾备。
10. MogileFS/FastDFS 的角色、故障域、扩容和 Nginx 代理实践。
11. Zabbix Agent/Proxy、主动模式、自定义模板、邮件短信和容量告警。
12. ELK Logstash 队列、TLS、ILM、分片、副本、脱敏和集群恢复。
13. Jenkins/GitLab 制品治理、扫描、审批、部署策略和密钥管理。
14. ZooKeeper quorum、选主、数据目录、滚动升级和恢复演练。
15. Kubernetes CNI、NetworkPolicy、Ingress Controller、PV/PVC、RBAC、升级、etcd 备份、审计和故障演练。
16. 全局运维能力：Ansible/IaC、SLO/SLI、变更管理、容量规划、应急响应、灾难恢复和安全合规。

## 版本原则

课程中的旧技术名词需要按当前版本校正：Heapster 改为 Metrics Server；Docker 与 OCI 分开说明；Kubernetes 网络按 CNI、Flannel、Calico 分层；MHA、Galera、Redis Sentinel 不混为同一种高可用方案。
