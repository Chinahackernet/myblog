我们知道在Django中的中间件的操作是我们定义好中间件，然后在settings.py的配置文件中的MIDDLEWARE部分加上我们定义好的中间件，在项目运行的时候其就会自动生效，如果我们不需要某个中间件，直接注释掉就不会生效，这就是可插拔式插件，其是怎么实现的呢？

  

首先定义如下项目目录结构：

![image.png](assets/python开发/4、可插拔式插件/4、可插拔式插件-1.png)

  

其中src.plugins下面的文件功能类似，伪代码如下（以basic.py为例）：

  

```python
class Basic(object):
    """采集基础信息：
        1、系统名
        2、ip地址
        ...
   """
    def process(self):
        return "this is basic"
```

> 注意：plugins下面的文件都有一个process方法

  

上面的步骤整理完后再在conf/settings.py中定义如下：

  

```python
# 定义需要执行的插件
COLLECT_PLUGINS = {
    "basic": "src.plugins.basic.Basic",
    "cpu": "src.plugins.cpu.Cpu",
    "memory": "src.plugins.memory.Memory",
    "nic": "src.plugins.nic.Nic",
}
```

> 注意：其中的值是文件定义的全路径加类名

  

然后要怎么实现呢？

我们在src.plugins下新建一个\_\_init\_\_.py文件，定义内容如下：

  

```python
from lib.config.settings import settings

class PluginsManager(object):
    def __init__(self):
        self.plugins = settings.COLLECT_PLUGINS
        self.response = {}

    def execute(self):
        # 1、循环settings.py中的COLLECT_PLUGINS，获取到键值对
        for key, value in self.plugins.items():
            # 2、获取到模块名和类名
            module_name, class_name = value.rsplit(".", 1)
            # 3、我们获取到了对应的字符串，现在由字符串导包
            import importlib
            module_path = importlib.import_module(module_name)
            # 4、获取类名
            cls = getattr(module_path, class_name)
            res = cls().process()
            self.response[key] = res
        return self.response
```

  

然后我们在bin.start.py中写如下代码：

```python
from src.plugins import PluginsManager

if __name__ == "__main__":
    res = PluginsManager().execute()
    print(res)

```

  

现在我们执行start.py就可以得到结果：

```python
{'basic': 'this is basic', 'cpu': 'this is cpu', 'memory': 'this is memory', 'nic': 'this is nic'}
```

  

如果我们不想执行某个插件，我们直接注释掉，如下：

  

```python
# 定义需要执行的插件
COLLECT_PLUGINS = {
    "basic": "src.plugins.basic.Basic",
    "cpu": "src.plugins.cpu.Cpu",
    "memory": "src.plugins.memory.Memory",
    #"nic": "src.plugins.nic.Nic",
}
```

  

然后我们再执行start.py，得到结果如下：

```python
{'basic': 'this is basic', 'cpu': 'this is cpu', 'memory': 'this is memory'}
```
