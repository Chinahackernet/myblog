在Django中，其有两个配置文件，settings.py是用户自定义配置文件，global\_settings.py是全局配置文件，其中全局配置文件不会经常去修改，settings.py是用户经常去修改的。但是我们在调用settings.py的时候依然可以访问global\_settings.py中定义的配置，这是怎么实现的呢？

  

首先创建一个python项目，创建如下的目录结构和文件：

![image.png](assets/python开发/3、高级配置文件实现方法/3、高级配置文件实现方法-1.png)

  

其中：

-   bin/start.py是项目的启动路径
-   conf/settings.py是用户自定义配置文件
-   lib/config/global\_settings.py是全局配置文件
-   lib/config/settings.py是将全局配置和用户自定义配置整合在一起的配置文件，它会用单例模式

> 规定：配置文件中定义的变量统一使用全大写。

  

首先，我们在conf/settings.py中定义如下内容：

```python
# 用户自定义配置
USER_ROOT = "user_root"
USER_PASS = "user_pass"
```

  

然后，在lib/config/global\_settings.py下定义如下内容：

```python
# 配置全局变量
GLOBAL_ROOT = "global_root"
GLOBAL_PASS = "global_pass"
```

  

最后我们主要配置lib/config/settings.py，核心代码如下：

```python
from conf import settings
from lib.config import global_settings

class Settings:
    def __init__(self):
        # 获取全局配置
        for key in dir(global_settings):
            if key.isupper():
                # 获取key值
                global_key = getattr(global_settings, key)
                # 在当前对象中设置key值
                setattr(self, key, global_key)

        for key in dir(settings):
            # print(key)
            if key.isupper():
                # 获取key值
                user_key = getattr(settings, key)
                # print(user_key)
                # 在当前对象中设置key值
                setattr(self, key, user_key)

settings = Settings()

```

> -   dir()用于获取属性列表
> -   getattr()利用反射获取属性的值
> -   setattr()设置属性的值
> -   isupper()是选取只有大写的key，因为我们规定key必须是全大写

  

然后我们在bin/start.py中写内容如下：

```python
from lib.config.settings import settings

if __name__ == "__main__":
    print(settings)
    print(settings.USER_ROOT)
    print(settings.GLOBAL_ROOT)
```

  

然后执行命令就可以获取到所有的属性值了。
