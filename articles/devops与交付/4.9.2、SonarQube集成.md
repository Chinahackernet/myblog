## 安装sonar-scanner

> 下载地址:[https://docs.sonarqube.org/latest/analysis/scan/sonarscanner/](https://docs.sonarqube.org/latest/analysis/scan/sonarscanner/)

```shell
https://binaries.sonarsource.com/Distribution/sonar-scanner-cli/sonar-scanner-cli-4.3.0.2102-linux.zip
```

  

将其解压到我们定义的安装目录，并添加环境变量

```shell
# 解压
unzip sonar-scanner-cli-4.3.0.2102-linux.zip -d /opt/
# 添加环境变量 vi /etc/profile
export SONARSCANNER_HOME="/opt/sonar-scanner-4.3.0.2102-linux"
export PATH=$PATH:$M2_HOME/bin:$ANT_HOME/bin:$GRADLE_HOME/bin:$NPM_HOME/bin:$JAVA_HOME/bin:$SONARSCANNER_HOME/bin
```

修改配置文件sonar-scanner.properties

```shell
#Configure here general information about the environment, such as SonarQube server connection details for example
#No information about specific project should appear here

#----- Default SonarQube server
sonar.host.url=http://10.1.10.21:9000

#----- Default source code encoding
sonar.sourceEncoding=UTF-8

```

```groovy

// 代码扫描
def SonarScan(projectName,projectDesc,projectPath){
    // sonarScanner安装地址
    def sonarHome = "/opt/sonar-scanner-4.3.0.2102-linux"
    // sonarqube服务端地址

    -Dsonar.projectKey=${projectName}  \
    -Dsonar.projectName=${projectName}  \
    -Dsonar.projectVersion=${scanTime} \
    -Dsonar.login=admin \
    -Dsonar.password=admin \
    -Dsonar.ws.timeout=30 \
    -Dsonar.projectDescription="${projectDesc}"  \
    -Dsonar.links.homepage=http://www.baidu.com \
    -Dsonar.sources=${projectPath} \
    -Dsonar.sourceEncoding=UTF-8 \
    -Dsonar.java.binaries=target/classes \
    -Dsonar.java.test.binaries=target/test-classes \
    -Dsonar.java.surefire.report=target/surefire-reports

    """
}
```

### 修改shareLibrary代码

```groovy
package org.devops

// 代码扫描
def SonarScan(projectName,projectDesc,projectPath){
    withSonarQubeEnv(credentialsId: 'sonarqube') {
        // sonarScanner安装地址
        def sonarHome = "/opt/sonar-scanner-4.3.0.2102-linux"
        // 以时间戳为版本
        def scanTime = sh returnStdout: true, script: 'date +%Y%m%d%H%m%S'
        scanTime = scanTime - "\n"
        sh """
        ${sonarHome}/bin/sonar-scanner  \
        -Dsonar.projectKey=${projectName}  \
        -Dsonar.projectName=${projectName}  \
        -Dsonar.projectVersion=${scanTime} \
        -Dsonar.ws.timeout=30 \
        -Dsonar.projectDescription="${projectDesc}"  \
        -Dsonar.links.homepage=http://www.baidu.com \
        -Dsonar.sources=${projectPath} \
        -Dsonar.sourceEncoding=UTF-8 \
        -Dsonar.java.binaries=target/classes \
        -Dsonar.java.test.binaries=target/test-classes \
        -Dsonar.java.surefire.report=target/surefire-reports

        echo "${projectName}  scan success!"
        """
    }
}
```

然后执行流水线即可，这种方式的优势在于可以直接从项目跳转到sonarqube。

  

### 多sonar优化

如果有多个sonar，并且是按环境区分，我们可以修改脚本如下：

```groovy
package org.devops

// 代码扫描
def SonarScan(sonarServer,projectName,projectDesc,projectPath){
    // 定义一个sonar服务列表
    def servers = ["sit":"sonarqube-sit","uat":"sonarqube-uat","pre":"sonarqube-pre","pro":"sonarqube-pro"]
    withSonarQubeEnv("${servers[sonarServer]}") {
        // sonarScanner安装地址
        def sonarHome = "/opt/sonar-scanner-4.3.0.2102-linux"
        // 以时间戳为版本
        def scanTime = sh returnStdout: true, script: 'date +%Y%m%d%H%m%S'
        scanTime = scanTime - "\n"
        sh """
        ${sonarHome}/bin/sonar-scanner  \
        -Dsonar.projectKey=${projectName}  \
        -Dsonar.projectName=${projectName}  \
        -Dsonar.projectVersion=${scanTime} \
        -Dsonar.ws.timeout=30 \
        -Dsonar.projectDescription="${projectDesc}"  \
        -Dsonar.links.homepage=http://www.baidu.com \
        -Dsonar.sources=${projectPath} \
        -Dsonar.sourceEncoding=UTF-8 \
        -Dsonar.java.binaries=target/classes \
        -Dsonar.java.test.binaries=target/test-classes \
        -Dsonar.java.surefire.report=target/surefire-reports

        echo "${projectName}  scan success!"
        """
    }
}
```

然后修改jenkinsfile，传递一个环境参数即可，当然也可以将环境定义在项目名中，然后获取环境传递也可以。
