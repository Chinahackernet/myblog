-   下载：[Download](https://ant.apache.org/bindownload.cgi)

## 安装ant

```plain
tar zxf apache-ant-1.10.5-bin.tar.gz -C /usr/local/
#添加全局变量（/etc/profile）
export ANT_HOME=/usr/local/apache-ant-1.10.5
export PATH=$PATH:$MAVEN_HOME/bin:$ANT_HOME/bin
source /etc/profile
```

-   测试

![](assets/devops与交付/4.1.2、集成ant/4.1.2、集成ant-2.png)

## Jenkins配置ant

-   系统设置->全局工具配置

![](assets/devops与交付/4.1.2、集成ant/4.1.2、集成ant-3.png)

-   编写Jenkinsfile

```plain
node {
stage ("build"){
    antHome = tool 'ANT'
    sh "${antHome}/bin/ant -version"
}
}
```

-   构建测试  
    

![](assets/devops与交付/4.1.2、集成ant/4.1.2、集成ant-4.png) 到此ant的集成就完成了
