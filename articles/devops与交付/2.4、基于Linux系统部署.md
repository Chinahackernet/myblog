# 容器化安装

> 确保服务器上已经安装了docker。如果没有安装，可以参考[https://www.yuque.com/rookieops/containers/dub64b](https://www.yuque.com/rookieops/containers/dub64b)

  

集合命令如下：

  

```shell
# 创建本地持久化目录
mkdir /opt/jenkins
# 创建本地用户
useradd jenkins
# 本地持久化目录授权
chown jenkins.jenkins /opt/jenkins -R
# 用docker起jenkins容器
docker run -d -p 8888:8080 -v /opt/jenkins:/var/jenkins_home --name jenkins --restart=always jenkins/jenkins
```

  

然后用网页打开http://IP:8888  根据步骤安装即可

  

# rpm安装

-   下载[软件包](https://mirrors.tuna.tsinghua.edu.cn/jenkins/redhat-stable/)
-   rpm –ivh jenkins-2.150.3-1.1.noarch.rpm #安装
-   service jenkins start #启动服务
-   chkconfig jenkins on #开机自启
