## 先决条件

-   JDK：在maven3.3 以上的版本需要JDK版本1.7+。内存：没有最低限制。
-   磁盘：1G+可用磁盘空间。 操作系统：没有限制。
-   下载maven [Download](http://maven.apache.org/download.cgi) ![](assets/devops与交付/4.1.1、集成Maven/4.1.1、集成Maven-1.png)

## 安装maven

```plain
tar zxf apache-maven-3.6.0-bin.tar.gz -C /usr/local/
#设置全局变量（/etc/profile）
export MAVEN_HOME=/usr/local/apache-maven-3.6.0
export PATH=$PATH:$MAVEN_HOME/bin
source /etc/profile
```

-   测试

![](assets/devops与交付/4.1.1、集成Maven/4.1.1、集成Maven-2.png)

## Jenkins配置maven

-   系统设置->全局工具配置

![](assets/devops与交付/4.1.1、集成Maven/4.1.1、集成Maven-3.png)

-   编写Jenkinsfile

```plain
node {
stage ("build"){
    mavenHome = tool 'M3'
    sh "${mavenHome}/bin/mvn -v"
}
}
```

-   构建测试  
    

![](assets/devops与交付/4.1.1、集成Maven/4.1.1、集成Maven-4.png) 到此jenkins集成maven就完成了。
