## checkout-拉取代码

### Git

```groovy
checkout([$class: 'GitSCM', branches: [[name: 'branchesName']],     
   			doGenerateSubmoduleConfigurations: false, 
			extensions: [], submoduleCfg: [], 
			userRemoteConfigs: [[credentialsId: "${credentialsId}",url: "${srcUrl}"]]])
```

其中：

-   branchesName是分支名
-   credentialsId是证书ID
-   srcUrl是代码url

  

### SVN

```groovy
checkout([$class: 'SubversionSCM', additionalCredentials: [], 
          excludedCommitMessages: '', excludedRegions: '', 
          excludedRevprop: '', excludedUsers: '', filterChangelog: false, 
          ignoreDirPropChanges: false, includedRegions: '', 
          locations: [[cancelProcessOnExternalsFail: true, credentialsId: '${credentialsId}', 
                       depthOption: 'infinity', ignoreExternalsOption: true, 
                       local: '.', remote: '${srcURL}']], quietOperation: true, 
          workspaceUpdater: [$class: 'UpdateUpdater']])
```
