（4）、修改Jenkinsfile

```groovy
// 使用jenkins nexus插件上传制品
def repoName = "maven-hostd"
def filePath = "target/${packageName}"
nexusArtifactUploader 	artifacts: [[artifactId: "${pomArtifact}", 
									classifier: '', 
									file: "${filePath}", 
									type: "${pomPackaging}"]], 
						credentialsId: 'nexus-admin-user',
						groupId: "${pomGroupId}",
						nexusUrl: '10.1.20.22:8081',
						nexusVersion: 'nexus3',
						protocol: 'http',
						repository: "${repoName}",
						version: "${pomVersion}"
```
