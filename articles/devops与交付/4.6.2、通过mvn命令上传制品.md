配置Jenkinsfile

```groovy
// 获取build完的包名
def packageName = sh returnStdout: true,script: "cd target;ls *jar"
packageName = packageName - "\n"

// 从pom.xml文件中读取信息
def pom = readMavenPom file: 'pom.xml'
pomVersion = "${pom.version}"
pomArtifact = "${pom.artifactId}"
pomPackaging = "${pom.packaging}"
pomGroupId = "${pom.groupId}"

// 上传制品
def mvnHome = tool "M2"
sh """
	cd target/
    ${mvnHome}/bin/mvn deploy:deploy-file -Dmaven.test.skip=true \
    	-Dfile=${packageName} -DgroupId=${pomGroupId} \
        -DartifactId=${pomArtifact} -Dversion=${pomVersion} \
        -Dpackaging=${pomPackaging} -DrepositoryId=maven-hostd \
        -Durl=http://10.1.10.22:8081/repository/maven-hostd
"""
```

注意：在上传制品的时候是需要认证的，当我们的指定的repositoryId和url后面指定不一致的时候，会报401的错误。所以我们需要在mvn的settings.xml中添加如下配置信息：

```xml
  <servers>
    <server>
      <id>maven-hostd</id>
      <username>admin</username>
      <password>admin</password>
    </server>
  </servers>
```

  

然后在nexus上创建repositroy maven-hostd，并开启允许deploy

如果遇到下面的错误

```groovy
[ERROR] Failed to execute goal org.apache.maven.plugins:maven-deploy-plugin:2.7:deploy-file (default-cli) on project standalone-pom: Failed to deploy artifacts: Could not transfer artifact com.mycompany.app:my-app:jar:1.1-20200506.122035-1 from/to maven-hostd (http://10.1.10.22:8081/repository/maven-hostd): Transfer failed for http://10.1.10.22:8081/repository/maven-hostd/com/mycompany/app/my-app/1.1-SNAPSHOT/my-app-1.1-20200506.122035-1.jar 400 Repository version policy: RELEASE does not allow version: 1.1-20200506.122035-1 -> [Help 1]
```

这是因为如果要使用deploy，版本号不能带有SNAPSHOT，我们修改pom.xml文件，例如：

```groovy
  <modelVersion>4.0.0</modelVersion>
  <groupId>com.mycompany.app</groupId>
  <artifactId>my-app</artifactId>
  <packaging>jar</packaging>
  <version>1.1</version>
  <name>my-app</name>
```

然后执行Jenkins pipeline，可以看到能够正常上传了
