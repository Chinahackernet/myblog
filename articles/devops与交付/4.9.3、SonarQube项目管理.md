### sonar扫描结果判断

如果sonar扫描失败，则邮件通知并退出pipeline。

#### 第一种，直接通过封装的方法获取

（1）、先判断扫描结果，如下，示例可以看[官网](https://docs.sonarqube.org/latest/analysis/scan/sonarscanner-for-jenkins/)。

```groovy
package org.devops

// 代码扫描
def SonarScan(sonarServer,projectName,projectDesc,projectPath){
    // 定义一个sonar服务列表
    def servers = ["sit":"sonarqube-sit","uat":"sonarqube-uat","pre":"sonarqube-pre","pro":"sonarqube-pro"]
    withSonarQubeEnv("${servers[sonarServer]}") {
        // sonarScanner安装地址
        def sonarHome = "/opt/sonar-scanner-4.3.0.2102-linux"
        // 以时间戳为版本
        def scanTime = sh returnStdout: true, script: 'date +%Y%m%d%H%m%S'
        scanTime = scanTime - "\n"
        sh """
        ${sonarHome}/bin/sonar-scanner  \
        -Dsonar.projectKey=${projectName}  \
        -Dsonar.projectName=${projectName}  \
        -Dsonar.projectVersion=${scanTime} \
        -Dsonar.ws.timeout=30 \
        -Dsonar.projectDescription="${projectDesc}"  \
        -Dsonar.links.homepage=http://www.baidu.com \
        -Dsonar.sources=${projectPath} \
        -Dsonar.sourceEncoding=UTF-8 \
        -Dsonar.java.binaries=target/classes \
        -Dsonar.java.test.binaries=target/test-classes \
        -Dsonar.java.surefire.report=target/surefire-reports
        """
    }
}

// 获取扫描状态
def GetScanStatus(){
    // 获取状态
    def qg = waitForQualityGate() 
    // 判断状态
    if (qg.status != 'OK') {
        error "Pipeline aborted due to quality gate failure: ${qg.status}"
    }
}
```

然后对应修改以下Jenkinsfile

```groovy
....
		stage("ScanStatus"){
			steps{
				timeout(time:30,unit:"MINUTES"){
                    script{
                        // 获取扫描状态
                    	tools.PrintMes("获取扫描结果状态","green")
						sonar.GetScanStatus()
                    }
        		}
			}
		}
...
```

但是这种方式有个小问题，就是时间非常慢。

  

#### 第二种，通过API获取

确认是否已经安装了Http Request插件，如果没有，如下步骤安装。

![image.png](assets/devops与交付/4.9.3、SonarQube项目管理/4.9.3、SonarQube项目管理-9.png)

（1）、先在Jenkins中添加sonar的凭据

![image.png](assets/devops与交付/4.9.3、SonarQube项目管理/4.9.3、SonarQube项目管理-10.png)

（2）、配置shareLibrary

新建一个sonarApi.groovy。

```groovy
package ore.devops

// 封装HTTP请求
def HttpReq(requestType,requestUrl,requestBody){
    // 定义sonar api接口
    def sonarServer = "http://10.1.10.21:9000/api"
    result = HttpRequest authentication: 'sonar-admin-user',
            httpMode: requestType,
            contentType: "APPLICATION_JSON",
            consoleLogResponseBody: true,
            ignotrSslErrors: true,
            requestBody: requestBody,
            url: "${sonarServer}/${requestUrl}"
    return result
}

// 获取soanr项目的状态
def GetSonarStatus(projectName){
    def apiUrl = "project_branches/list?project=${projectName}"
    // 发请求
    response = HttpReq("GET",apiUrl,"")
    // 对返回的文本做JSON解析
    response = readJSON text: """${response.content}"""
    // 获取状态值
    result = response["branches"][0]["status"]["qualityGateStatus"]
    return result
}
```

然后我们到Jenkinsfile中去引用它。

```groovy
...
        stage("ScanStatus"){
			steps{
				timeout(time:30,unit:"MINUTES"){
                    script{
                        // 获取扫描状态
                    	tools.PrintMes("获取扫描结果状态","green")
						res = sonarapi.GetSonarStatus("${JOB_NAME}")
						// 对结果进行判断
						if (res.toString() == "ERROR"){
                            // 发邮件通知
							sendEmail.SendEmail("代码扫描失败",toEmailUser)
							error "代码扫描失败."
						}
                    }
        		}
			}
		}
...
```
