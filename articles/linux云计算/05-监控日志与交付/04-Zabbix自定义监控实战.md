# Zabbix 自定义监控实战

## 设计

自定义指标应有名称、单位、采集周期、异常阈值、标签和对应 Runbook。脚本只输出数值或规范化文本，错误写入 stderr 并返回非零状态。

```bash
zabbix_get -s <AGENT> -k 'system.run["/usr/local/bin/check_app.sh"]'
```

## 监控对象

常见自定义项包括 TCP 连接数、进程存活、URL 状态码、Redis 内存、MySQL 复制延迟和证书到期时间。先在单台测试主机验证权限、超时和采集频率，再创建模板与触发器。

告警必须避免重复、抖动和无负责人；恢复表达式、依赖关系和维护窗口应一并配置。
