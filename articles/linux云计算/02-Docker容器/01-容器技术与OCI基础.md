# 容器技术与 OCI 基础

容器通过 Linux namespaces 隔离进程视图，通过 cgroups 控制资源，通过镜像分发应用文件系统。容器共享宿主机内核，因此不是传统虚拟机的安全边界替代品。

## 核心对象

```text
镜像（不可变模板） → 容器（运行实例）
镜像层（只读） + 容器层（可写）
```

OCI 主要定义镜像格式和运行时规范。Docker CLI、containerd 和 runc 是常见实现链路；理解分层关系有助于定位镜像、运行时和网络问题。

## 生产原则

- 镜像固定版本或 digest，不使用 `latest` 作为生产唯一标识。
- 容器内进程尽量以前台方式运行，日志输出到 stdout/stderr。
- 配置、密码和业务数据与镜像分离。
- 使用非 root 用户、只读根文件系统和最小 Linux capability。
