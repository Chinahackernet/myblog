# Linux 主机初始化与安全基线

## 目标

建立可审计、可维护、最小暴露面的 Linux 主机。所有变更都应记录主机名、时间、操作者和回滚方式。

## 1. 资产与系统确认

```bash
hostnamectl
cat /etc/os-release
ip -br addr
lsblk
df -hT
```

确认系统版本、网卡地址、磁盘布局和挂载点，避免在错误主机上操作。

## 2. 时间与软件源

```bash
timedatectl
systemctl enable --now chronyd 2>/dev/null || systemctl enable --now systemd-timesyncd
```

时间偏差会影响日志排序、证书校验和集群一致性。生产环境应统一时间源。

## 3. 账号与 SSH

```bash
getent passwd
awk -F: '$3==0 {print $1}' /etc/passwd
sshd -T | egrep 'permitrootlogin|passwordauthentication|pubkeyauthentication'
```

建议使用个人账号加 `sudo`，使用密钥登录，并在确认新会话可以登录后再关闭密码登录。不要直接关闭当前 SSH 会话。

## 4. 防火墙与最小开放

```bash
ss -lntup
firewall-cmd --list-all 2>/dev/null || ufw status verbose
```

只开放业务必需端口；先确认管理入口、监控入口和应用端口，再写入防火墙规则。

## 5. 验收清单

- 主机名和 IP 已登记
- 时间同步正常
- 管理账号可用，root 远程登录策略符合要求
- 防火墙规则经过复核
- SSH、系统和业务日志已纳入采集
