# Linux 性能分析方法

## 分析原则

采用 USE（Utilization、Saturation、Errors）方法：先确认资源利用率，再确认排队/饱和，最后寻找错误证据。不要仅凭 load average 判断根因。

## CPU 与负载

```bash
uptime
mpstat -P ALL 1 5
pidstat -u -p ALL 1 5
```

区分 user、system、iowait 和 steal。虚拟机出现 steal 较高时，应检查宿主机或云平台资源。

## 内存

```bash
free -h
vmstat 1 5
cat /proc/pressure/memory
```

重点看 swap 活动、available 内存和 PSI（Pressure Stall Information）。不要把 `free` 列直接当成可用内存。

## 磁盘 IO

```bash
iostat -xz 1 5
pidstat -d 1 5
cat /proc/pressure/io
```

观察设备利用率、await、队列长度和 IO PSI，并与应用延迟、数据库慢查询关联。

## 处理原则

先采集证据，再缓解；保留命令输出和时间点。不要为了“降负载”直接终止未知进程或清空缓存。任何重启都必须有影响评估和回滚方案。
