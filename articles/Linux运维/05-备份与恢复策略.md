# Linux 备份与恢复策略

## 目标

备份不是“复制文件”，而是能够在规定时间内恢复业务。先定义 RPO（可接受的数据丢失量）和 RTO（可接受的恢复时间）。

## 1. 文件备份示例

```bash
tar -czf /backup/etc-$(date +%F).tar.gz /etc
rsync -aHAX --delete /srv/data/ /backup/data/
```

生产环境使用 `--delete` 前必须确认源和目标目录，避免方向写反。备份目录应有权限隔离和容量监控。

## 2. 校验与保留

```bash
sha256sum /backup/etc-*.tar.gz | tail
tar -tzf /backup/etc-2026-01-01.tar.gz | head
```

采用日、周、月分层保留，并至少保留一份与生产环境隔离的副本。备份成功不等于可恢复，必须定期演练。

## 3. 恢复演练

1. 记录备份版本、恢复目标和负责人。
2. 在隔离环境恢复文件或数据库。
3. 校验权限、属主、配置、服务启动和业务读写。
4. 记录耗时、缺失项和改进措施。

## 4. 事故注意事项

- 勿直接覆盖生产数据，先保留现场和当前版本。
- 恢复前确认备份来源、时间点和完整性。
- 密钥、密码和个人数据应加密保存，不能放入公开仓库。
