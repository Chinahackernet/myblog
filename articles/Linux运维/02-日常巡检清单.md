# Linux 日常巡检清单

## 1. 资源概况

```bash
uptime
free -h
df -hT
df -ih
top -b -n1 | head -20
```

重点观察 CPU 持续高、内存交换、磁盘或 inode 使用率接近阈值。阈值应按业务基线设定，不能只看一次采样。

## 2. 进程与服务

```bash
systemctl --failed
systemctl status nginx --no-pager
ps -eo pid,ppid,user,%cpu,%mem,stat,cmd --sort=-%cpu | head
```

发现异常进程时，先记录 PID、启动时间、命令行和父进程，再决定是否重启。不要直接 `kill -9`，除非已确认常规停止无效。

## 3. 磁盘与 IO

```bash
lsblk -f
iostat -xz 1 3  # 需要 sysstat
du -xhd1 /var 2>/dev/null | sort -h
lsof +L1 2>/dev/null
```

删除日志前先确认保留策略。`lsof +L1` 可帮助发现“文件已删除但进程仍占用”的空间。

## 4. 内核与系统错误

```bash
dmesg -T --level=err,warn | tail -50
journalctl -p warning -b --no-pager | tail -100
```

将异常与业务监控、发布记录和变更记录对齐，避免只凭单条日志下结论。

## 5. 巡检记录模板

```text
主机：
时间：
变更/发布：
CPU/内存/磁盘：
服务状态：
异常日志：
处理动作：
后续跟进：
```
