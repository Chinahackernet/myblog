# Docker 资源限制与容器安全

## 资源约束

```bash
docker run -d --memory=512m --cpus=1.0 --pids-limit=200 <IMAGE>
docker stats --no-stream
```

限制应依据压测和业务基线设置；过低会造成 OOM 或节流，过高则无法保护宿主机。监控内存工作集、CPU throttling、重启次数和退出码。

## 安全基线

- 不挂载 `/var/run/docker.sock` 到普通业务容器。
- 删除不必要 capability，优先 `--read-only` 并单独挂载可写目录。
- 使用 secrets 管理凭证，禁止写入镜像层和命令行历史。
- 宿主机、Docker Engine、镜像基础层都要纳入补丁和漏洞管理。
