# Linux 日常巡检清单

## 巡检原则

巡检应关注趋势、变化和风险，而不是机械地执行命令。每项结果都要带主机、时间、阈值、最近变更和责任人；没有行动路径的指标不应成为告警。

## 1. 资源与系统

```bash
uptime; free -h; df -hT; df -ih
systemctl --failed; journalctl --since '24 hours ago' -p warning
```

检查 load 与 CPU 核数的关系、内存回收和 swap、文件系统水位/inode、失败服务、内核 OOM、时钟偏差和证书剩余天数。磁盘达到预警阈值时先定位增长来源，再决定清理或扩容，禁止直接删除未知日志。

## 2. 网络与安全

```bash
ss -s; ip -s link; ip neigh; nft list ruleset
last -a | head; ausearch -m USER_LOGIN --start today
```

关注丢包、错误包、邻居抖动、异常出站连接、失败登录和权限变化。对外暴露主机每日核对端口清单和证书链，对高风险主机核对漏洞扫描结果和补丁例外到期时间。

## 3. 业务检查

从监控系统查看请求成功率、P95/P99、队列、数据库连接、备份最近成功时间和复制延迟；用合成探针验证关键事务，而不是只访问首页。

## 输出模板

```text
主机/服务：
窗口与版本：
异常指标及证据：
影响评估：
立即动作与负责人：
后续工单与截止时间：
```
