在前端页面中，会有许多css/js/image等静态文件，在gin中只需要做以下配置。

  

比如项目目录如下：

![image.png](assets/go开发/4.2、静态文件的使用/4.2、静态文件的使用-1.png)

  

然后index.html内容如下

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Title</title>
</head>
<body>
<img src="/static/images/1.jpg">
<h1>你好</h1>

</body>
</html>
```

  

在主函数中做以下配置，则可以正常读取静态图片了，如下：

```go
package main

import (
	"github.com/gin-gonic/gin"
	"net/http"
)

func Hello(ctx *gin.Context){
	ctx.HTML(http.StatusOK,"index.html",nil)
}

func main() {
	router := gin.Default()
	router.Static("/static","static")
	router.LoadHTMLGlob("templates/*")
	router.GET("/",Hello)
	router.Run()
}
```
