1.  准备好内核升级包

-   wget [https://public-fileserver.oss-cn-hangzhou.aliyuncs.com/Infra/kernel\_3.10.0-1127.13.1.el7.tar.gz](https://public-fileserver.oss-cn-hangzhou.aliyuncs.com/Infra/kernel_3.10.0-1127.13.1.el7.tar.gz)
-   放到cargo服务器/tmp下
-   cd /compass/common/all-in-one/mirrors/centos
-   tar -xvf /tmp/kernel\_3.10.0-1127.13.1.el7.tar.gz

2.  检查

  

```
如果内核版本已经 >= 3.10.0-1062.4.1.el7.x86_64, 且内核启动参数已添加"cgroup.memory=nokmem", 则无须再作任何操作.
如果内核版本已经 >= 3.10.0-1062.4.1.el7.x86_64, 但内核启动参数未添加"cgroup.memory=nokmem", 则可跳过步骤: 4, 7.a.
其他则仍按顺序操作.
curVersion="$(uname -r)"
declare -r reqVersion="3.10.0-1062.4.1.el7.x86_64"
verSatisfied="$(python2 -c "
from distutils.version import LooseVersion
if LooseVersion('$curVersion') >= LooseVersion('$reqVersion'):
    print('True')
else:
    print('False')
")"

if grep -qE '\s+cgroup\.memory=nokmem(\s|$)+' /proc/cmdline; then
    nokmemCmdline='True'
else
    nokmemCmdline='False'
fi

if [[ "$verSatisfied" = 'True' ]]; then
    if [[ "$nokmemCmdline" = 'True' ]]; then
        printf '%s\n' 'kmem accounting already disabled, NO further action needed.'
    else
        printf '%s\n' 'kernel version already satisfied, but GRUB not properly configured, PLS SKIP STEP 4, 7.a.'
    fi
else
    printf '%s\n' 'kmem accounting is NOT disabled, PLS go through following steps.'
fi
```

  

3.  添加新的repo

  

```
export download_url="http://102.212.30:3142"
cat > /etc/yum.repos.d/CentOS-kernel-3.10.0-1127.13.1.repo <<- EOF
[kernel-3.10.0-1127.13.1]
name=CentOS-kernel-3.10.0-1127.13.1
baseurl=$download_url/centos/kernel-3.10.0-1127.13.1/
gpgcheck=0
enabled=0
EOF
```

  

4.  检查集群健康状态

  

-   kubectl get nodes | grep -vE '\\s+Ready\\s+'
-   kubectl get pods --no-headers --all-namespaces -o wide | grep -vE 'Running|\\s+Completed\\s+'

  

5.  驱逐

  

-   kubectl drain 节点0 --delete-local-data --ignore-daemonsets

  

6.  更新kernel

  

```
yum clean all
yum --disablerepo="*" --enablerepo="kernel-3.10.0-1127.13.1" -y update kernel kernel-devel kernel-headers
```

  

7.  更新grub

  

```
grep -qE "^GRUB_CMDLINE_LINUX=.*cgroup.memory=nokmem" /etc/default/grub || sed -Ei "s%^(GRUB_CMDLINE_LINUX=.*)\"\s*$%\1 cgroup.memory=nokmem\"%" /etc/default/grub

if [[ -d /sys/firmware/efi ]]; then
    grub2-mkconfig -o /boot/efi/EFI/centos/grub.cfg
else
    grub2-mkconfig -o /boot/grub2/grub.cfg
fi
```

  

8.  重启

  

-   reboot

  

9.  检查内核版本

  

```
uname -r
cat /proc/cmdline |grep nokmem
```

  

10.  GPU节点

  

```
systemctl stop kubelet.service docker.service
rmmod -f nvidia_uvm nvidia_drm nvidia_modeset nvidia nouveau

nv_drv_ver="$(ls -l /usr/lib64/libnvidia-ml.so.1 | sed -r 's#.*libnvidia\-ml\.so\.(.*)#\1#')"
cd ~/.clever/driver
bash "NVIDIA-Linux-x86_64-${nv_drv_ver}.run" -s -Z
systemctl start docker.service kubelet.service
```

  

11.  恢复节点调度

  

-   kubectl uncordon 节点0

```
kubectl get nodes | grep -vE '\s+Ready\s+'
kubectl get pods --no-headers --all-namespaces -o wide | grep -vE 'Running|\s+Completed\s+'
```
