# 唯一约束

> 分类：Database / 第7章：SQL约束
> 原文：https://www.cuiliangblog.cn/detail/section/31451718
> 来源：崔亮的博客

---

    1. 表列中不允许有重复值，但是可以有空值
    2. 语法
    - 列级定义
+ create  table t1 (id int unique,name char(10));
    - 表级定义
+ create  table t2 (id int,name char(10),unique(id));
    - 追加定义
+ create  table t3(id int,name char(10));
+ alter table t3 modify id int unique;
+ ![](assets/07-Database/7a9fd96b207667bd7a51.png)
    - 测试
+ insert  into t1 values(1,'a');
+ insert  into t1 values(1, 'a'); 报错，id中不允许重值，2个1
+ insert  into t1 values(null, 'b'); 成功，id允许有空值
    - 删除unique约束
+ show  keys from t1;
+ ![](assets/07-Database/4befa847ab4188e432ed.png)
+ drop  index id on t1;
+ desc  t1;
+ ![](assets/07-Database/25a09d01421156ab5de9.png)
+ drop  table t1,t2,t3;
